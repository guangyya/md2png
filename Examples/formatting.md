# Markdown formatting

Use **bold** for the outcome, *italic* for nuance, and ~~strikethrough~~ for a
decision that has changed. Inline values such as `rendering: local-only` stay
compact and readable.

## Key message

> The image is created locally. Review it before pasting, and send it yourself.

### Useful details

- Headings create a clear visual hierarchy.
- A normal link keeps its label: [Project documentation](../README.md).
- A horizontal rule can separate the summary from supporting information.
